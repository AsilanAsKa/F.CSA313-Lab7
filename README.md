## Зорилго

Уншлагын жагсаалт веб аппликейшнийг exploratory testing аргаар шалгаж, хэрэглэгчийн интерфейс болон API-ийн алдааг илрүүлэх.

## Тестийн хүрээ

- Ном нэмэх, хайх, устгах үйлдэл
- Номын тоолуур болон жилийн утга
- Хэрэглэгчид харагдах мессеж
- Хуудасны холбоосууд
- API хүсэлт, хариу болон алдаатай JSON өгөгдөл

## Илрүүлсэн алдаанууд

1. **BUG-01:** Буруу JSON хүсэлтэд API `400 Bad Request` биш `200 OK` буцаадаг.
2. **BUG-02:** Хуучин хувилбарын холбоос `500 Internal Server Error` буцаадаг.
3. **BUG-03:** Номын жагсаалт 3 номтой байхад API-ийн статистик `total: 4` гэж буцаадаг.

Алдааны дэлгэрэнгүй тайлан `bugs/` хавтсанд, API нотолгоонууд `evidence/` хавтсанд байрлана.

## Дүгнэлт

1. Exploratory testing нь урьдчилан төлөвлөсөн шалгалтаас гадна аппын бодит үйлдлийг судалж алдаа олоход тусалсан.
2. API-ийн алдаатай JSON хүсэлт илгээсэн Saboteur аялал үр дүнтэй байв.
3. BUG-01 нь алдаатай хүсэлтэд буруу HTTP статус буцааснаар илэрсэн.
4. BUG-02 нь хуудасны холбоосыг шалгах үед илэрсэн.
5. BUG-03 нь номын жагсаалт болон статистикийн хариуг харьцуулах үед илэрсэн.
6. API-ийн алдааг `curl -i` командаар шалгаж, бүрэн хариуг нотолгоо болгон хадгалсан.
7. Автомат тестээр API статус болон тоолуурын зөрүүг шалгаж болно.
8. Харин өнгө, харагдах байдал, хэрэглэгчид ойлгомжтой эсэхийг хүн гараар шалгах нь чухал.
9. Цаашид хоосон талбар, давхардсан ном, буруу он, том хэмжээний текст болон том жижиг үсэг ялгадаг хайлтыг шалгах шаардлагатай.
