## Зорилго

Уншлагын жагсаалт веб аппликейшнийг exploratory testing аргаар шалгаж, хэрэглэгчийн интерфейс, өгөгдлийн баталгаажуулалт болон API-ийн асуудлыг илрүүлэх.

## Тестийн хүрээ

- Ном нэмэх, хайх, устгах
- Хоосон болон дутуу оролт
- Оны зөвшөөрөгдөх хүрээ
- Хайлтын том, жижиг үсгийн боловсруулалт
- Номын тоолуур болон API статистик
- API хүсэлт, хариу

## Charter

- **Couch Potato:** Хоосон болон дутуу оролт, өгөгдлийн баталгаажуулалт.
- **Supermodel:** GUI, ном нэмэх, хайх, устгах болон харагдах байдал.
- **Saboteur:** API хүсэлт болон алдаатай өгөгдлийн боловсруулалт.
- **Fed-Ex:** Ном нэмэх, жагсаалтад харагдах, устгах үеийн өгөгдлийн урсгал.

## Дүгнэлт

1. Couch Potato аялал хоосон болон буруу утгатай оролтын баталгаажуулалтыг шалгахад үр дүнтэй байв.
2. Номын нэр хоосон үед нэмэгдэж байгааг илрүүлсэн.
3. Charter-д заасан 1000–2100 оны хязгаараас гадуурх 999 утга зөвшөөрөгдсөн.
4. Supermodel аяллаар хайлтын том, жижиг үсгийн боловсруулалтыг шалгасан.
5. `clean code` хайлт `Clean Code` номыг олоогүй нь хайлтын логикийн асуудлыг харуулсан.
6. Saboteur аяллаар API-ийн номын жагсаалт болон статистикийн total утгыг харьцуулсан.
7. BUG-04-ийн статистикийн зөрүү session үеэр 7 ба 8, цэвэр төлөвийн дахин шалгалтаар 3 ба 4 гэсэн үр дүнгээр батлагдсан.
8. Өмнөх автомат/API шалгалтууд malformed JSON болон статистикийн зөрүүг илрүүлсэн боловч хүний session-ийн олдворуудаас тусад нь бүртгэсэн.
9. Хүний exploratory testing нь хэрэглэгчийн үйлдлийн дараалал, гэнэтийн оролт болон интерфэйсийн зан төлөвийг судлахад үр дүнтэй байв.
