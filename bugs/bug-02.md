# BUG-02: Хуучин хувилбарын линк 500 алдаа буцаадаг

Орчин: Уншлагын жагсаалт v2.0, Ubuntu 24.04, Node.js, 2026-10-20

Урьдчилсан нөхцөл: Апп localhost:3000 дээр ажиллаж байна.

## Дахин гаргах алхам

1. Браузераар `http://localhost:3000` хаягийг нээнэ.
2. Хуудасны доод хэсгийн `Хуучин хувилбар` линкийг дарна.
3. Нээгдсэн хуудасны үр дүнг шалгана.

Хүлээгдэж байсан: Линк ажиллаж, хуучин хувилбарын хуудас нээгдэнэ.

Бодит үр дүн: Хуудас HTTP 500 Internal Server Error алдаа буцаадаг.

Ноцтой байдал: Major — хэрэглэгч хуудасны холбоосоор орж чадахгүй.

Хавсралт: `evidence/bug-02-curl.txt`

Олдсон аялал: Supermodel — хэрэглэгчийн интерфейс болон холбоосыг шалгасан. API нотолгоог curl ашиглан баталгаажуулсан.
