# BUG-01: Буруу JSON хүсэлтэд API 200 OK буцаадаг

Орчин: Уншлагын жагсаалт v2.0, Ubuntu 24.04, Node.js, 2026-10-20

Урьдчилсан нөхцөл: Аппыг шинээр асаасан, localhost:3000 дээр ажиллаж байна.

## Дахин гаргах алхам

1. Аппыг ажиллуулна: `node app.js`.
2. Terminal дээр дараах командыг ажиллуулна:

   `curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d '{"title":'`

3. HTTP статус болон хариуг ажиглана.

Хүлээгдэж байсан: Буруу JSON хүсэлтэд HTTP 400 Bad Request буцна.

Бодит үр дүн: HTTP 200 OK болон `{"result":"OK"}` хариу буцсан.

Ноцтой байдал: Major — API-ийн алдаатай хүсэлт амжилттай болсон мэт харагдаж, клиент буруу үр дүнг амжилт гэж ойлгож болно.

Хавсралт: `evidence/bug-01-curl.txt`

Олдсон аялал: Saboteur — API руу зориуд буруу өгөгдөл илгээж шалгасан.
