# BUG-03: Нийт номын тоолуур бодит тооноос нэгээр их

Орчин: Уншлагын жагсаалт v2.0, Ubuntu 24.04, Node.js, 2026-10-20

Урьдчилсан нөхцөл: Аппыг шинээр асаасан, анхны 3 ном жагсаалтад байна.

## Дахин гаргах алхам

1. Аппыг шинээр асаана: `node app.js`.
2. `curl -s http://localhost:3000/api/books` командыг ажиллуулж номын жагсаалтыг авна.
3. `curl -s http://localhost:3000/api/stats` командыг ажиллуулж тоолуурын мэдээллийг авна.
4. Хоёр хариултын номын тоог харьцуулна.

Хүлээгдэж байсан: `total` нь жагсаалтад байгаа номын тоотой тэнцүү буюу 3 байна.

Бодит үр дүн: `/api/books` гурван ном буцаасан боловч `/api/stats` `total: 4` гэж буцаасан.

Ноцтой байдал: Major — номын тоолуур буруу мэдээлэл харуулж байна.

Хавсралт: `evidence/bug-03-curl.txt`

Олдсон аялал: Saboteur — API-ийн өгөгдөл болон статистикийг харьцуулсан.
